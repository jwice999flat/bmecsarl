# Site institutionnel B-MEC SARL

Version statique responsive du site « Obsidian Construction & BMEC Heritage ».

## Ouvrir le site

Ouvrez `index.html` dans un navigateur moderne. Pour un aperçu local plus fidèle, lancez un petit serveur HTTP depuis ce dossier, par exemple :

```bash
python3 -m http.server 8080
```

Puis ouvrez `http://localhost:8080`.

## Fichiers

- `index.html` : structure, contenu français et métadonnées SEO ;
- `blog.html` : page de regroupement et filtrage des publications ;
- `articles/` : quatre articles complets rédigés par Jane Doe ;
- `styles.css` : identité visuelle, animations et responsive design ;
- `script.js` : thème clair/sombre persistant, menu mobile, filtres, formulaire, dialogues et animations ;
- `assets/logo_bmec.svg` et `assets/favicon_bmec.svg` : identité visuelle officielle B-MEC ;
- `assets/facebook.svg`, `assets/linkedin.svg` et `assets/instagram.svg` : icônes sociales officielles.
